GPS-D / Navigation

Contested navigation is a SPEARHEAD baseline.

GPS-denied

EO/LWIR + inertial + RF relative navigation for DDIL environments.

M-Code GPS

Military grade GPS which degrades to GPS-D when contested.

Offboard / C2 nav

C2 guided navigation - FAAD control with cueing - for multiple missions (ISR-T, terminal engagement, and others).

Power / Fuel

Hybrid fuel-electric density on HAMR; high-energy battery packs on ZEVO; ground power delivery mission packages.

HAMR hybrid

EFI computer-controlled piston engine + generator powering six independent electric motors. Remote in-flight engine start/restart using onboard batteries. Payload power: 200 W continuous / 2 kW peak @ 48 VDC.

Electric / recharge missions

ZEVO enables battery exchange for distributed forces and carries high-density packs for 30 km multi-mission flights. Land-and-power packages allow HAMR to act as a mobile edge power node for distributed forces.
